# .cursorrules - Business Management Application Rules

## Technology Stack
- Framework: Laravel 12 (PHP 8.3+)
- Frontend: Inertia.js (React 18/19 + TypeScript)
- UI/Styling: Tailwind CSS + shadcn/ui
- Database: MySQL 8.0+

## Architecture & Modular Isolation Rules
1. Core Directory Rules:
   - Shared models/services live strictly in `app/Modules/Core/`.
   - Task Management logic lives strictly in `app/Modules/TaskManagement/`.
   - Do not recreate `app/Modules/Crm/` or a client portal.

2. Domain Separation (STRICT):
   - Work clients are `tm_companies`, shown at `/tasks/clients`.
   - Shared entities (Users, Employees, Roles, Media) must remain in `app/Modules/Core/`.
   - Core must never import Task Management.

3. Frontend Rules:
   - React components must be fully typed using TypeScript.
   - Use shadcn/ui components for form controls, dialogs, dropdowns, and tables.
   - Place Inertia pages in `resources/js/Pages/Core/` and `resources/js/Pages/TaskManagement/`.
